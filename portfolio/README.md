# Haridas Satheesh — Systems, Innovation & Project Portfolio

I work at the intersection of **enterprise transformation, EPMO, automation, analytics, AI agents, decision systems, predictive intelligence, hardware experimentation, and applied systems thinking**.

A recurring pattern across my work is:

> **Observe the system → identify hidden variables → structure the data → create feedback loops → predict what may happen → recommend or automate an action → measure the result → improve the system.**

This portfolio intentionally includes both software and physical-system work. Some projects were implemented professionally, some were built as private engineering projects, some reached prototype/research stage, and some were deliberately stopped after market or feasibility analysis.

## How to read this portfolio

This is not a list of buzzwords. Each section separates:
- the problem,
- the system idea or implementation,
- the technologies/approaches involved,
- and the actual maturity level.

Some names represent successive versions of the same research stream. They are preserved because they show how an idea evolved rather than pretending every concept was a separate shipped product.
