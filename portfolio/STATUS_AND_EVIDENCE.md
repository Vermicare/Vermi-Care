# Status & Evidence Rules

This portfolio uses explicit maturity labels so that research, prototypes, and production work are not mixed together.

| Label | Meaning |
|---|---|
| **Implemented — Professional** | Delivered in a real work environment as part of professional responsibilities. |
| **Implemented — Personal/Open Project** | Built outside employer delivery, with a working repository/system/artifact. |
| **Prototype** | A tangible prototype, technical design, test build, or project artifact exists, but it is not represented as production-ready. |
| **Research Program** | Structured research with defined passes, evidence synthesis, models, or implementation recommendations. |
| **Concept / Architecture** | System design, architecture, simulation, or product concept developed in depth but not claimed as deployed. |
| **In Progress** | Active engineering or research work. |
| **Archived Exploration** | Deliberately paused or rejected after feasibility/market analysis. |

## Evidence principles

1. No concept is described as production deployment.
2. No employer/client confidential information is published.
3. No proprietary source code or internal datasets are copied into this portfolio.
4. Metrics are included only when already documented or verifiable.
5. Related concept names are grouped into a single evolution stream where appropriate.
